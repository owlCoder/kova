# @kova/vscode

Reserved composition root and workspace adapter boundary. Future activation constructs Core implementations, provider, tool registry, permissions, hooks, guardrails and MCP. VS Code APIs, realpath, process management, WorkspaceEdit, diff documents, settings, commands and the Output channel remain here.

The manifest will contribute one activity-bar view, `kova.chat`, and commands to open/new chat, select skills and open settings. No activation entry point or installable extension exists yet.
